# Canvas Audio Codec Demo Reference

These files are copied from the Canvas final-project audio codec demo:

- `sockit_top_original.v` - original demo top-level wrapper.
- `audio_effects_original.v` - original sine/feedback demo logic.
- `sockit_top_original.ucf` - original audio demo constraints.
- `canvas_audio_demo_README.txt` - original demo readme.

They are included for traceability and comparison only. The final project integration should use `../../src/audio_frontend.v` instead of the original `sockit_top` module.
