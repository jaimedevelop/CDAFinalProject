This may or may not happen to you:
When you try to generate a bit file you should receive an Error stating something along the lines of "place this inside your ucf file to bypass as a warning"

- Copy the whole line of text in between < > and paste into your ucf file.

It will look something like this :

PIN "instance_name/clkout2_buf.O" CLOCK_DEDICATED_ROUTE = FALSE;

Yours will be unique to what you have named the module you created with the clock wizard.

Also, all of the clock wizard IPs can be generated by you again, so do that if you face any issues.
